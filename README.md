# Nigeria Sales Analysis — Excel Dashboard

## Project Overview
Analyzed a messy Nigerian sales dataset (2023–2025) covering 138 transactions across 20 states. Cleaned the data, built pivot tables, and created an interactive dashboard with slicers showing sales performance by state, product, month, and channel.

## Tools Used
- Microsoft Excel (Data Cleaning, Pivot Tables, PivotCharts, Slicers)

## Data Cleaning Steps
- Standardized inconsistent state names (e.g., "rivers" → "Rivers")
- Standardized product names (e.g., "KEYBOARD" → "Keyboard")
- Removed rows with no usable data
- Recovered missing Total Sale values using Units × Unit Price
- Resulted in 138 clean, analysis-ready rows

## Dashboard Features
- Sales by State: Bar chart, sorted descending (Kano leads)
- Sales by Product: Bar chart showing Keyboard as top seller
- Monthly Trend: Bar chart showing seasonal peaks in March and July
- Sales by Channel: Pie chart showing Online dominance
- Interactive Slicers: Filter by State and Product

## Key Insights
1. Kano leads total sales, followed by Benue, Rivers, and Delta.
2. Keyboards are the top-selling product category.
3. Sales peak in March and July; lowest in June.
4. Online (30%) and Retail (28%) dominate revenue channels.
5. Total revenue analyzed: ₦969,297,752.
